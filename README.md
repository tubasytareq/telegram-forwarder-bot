# Telegram Forwarder Bot

This project is a Python bot that automatically forwards messages (text + media) from a source Telegram channel to a target channel. 

**Features:**
- Forwards messages instantly
- Sends text, images, videos, and files
- Does not show "forwarded from" attribution
- Works with a user account session

**Setup:**
1. Save your Telegram API ID, API Hash, and Bot Token as secrets.
2. Run `bot.py` on a persistent server or Replit with Always-On (VM).
3. The bot will forward messages continuously.
